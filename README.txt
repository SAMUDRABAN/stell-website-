Steel Brokerage Website — Version 2

Complete three-page website with animations and interactive 3D steel models.

To preview with all 3D features, serve this folder using a local web server (ES modules require HTTP rather than opening index.html directly).
If Python 3 is installed: open Terminal in this folder and run:
python3 -m http.server 8000
Then visit http://localhost:8000

Google Fonts requires internet access. Website files and 3D libraries are included.
Business identity and contact details remain pending. The enquiry form prepares a brief locally; it does not send messages.
